# 混元 / Cube Sandbox 接入

在逻辑层之外再加**环境级兜底**，形成纵深防御。

## 步骤
1. 逻辑层：同通用 API，在工具执行前调统一内核 `evaluate(...)`。
2. 环境级：在容器 / VM 配置网络与文件系统边界：
   - 限制出网（仅允许白名单域名）；
   - 沙盒内文件系统只读或限定目录；
   - 即便模型试图绕开逻辑层，环境层也拦得住（不依赖模型配合）。
3. 两层叠加即纵深防御；控制权越底层越不可绕过。

## 说明
- 混元侧信息来自腾讯云开发者社区，**未本机验证**适配成本；具体沙箱策略以平台为准。
- 环境级是「最硬」一层，但需容器 / VM / OS 配置权。
